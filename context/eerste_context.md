# DOEL

ik wil een applicatie ontwikkelen die gebruikers laat reflecteren over de carbon footprint van hun AI gebruik. 

## bestaande initiatieven
- https://codecarbon.io/ : measure the environmental footprint of compute and genAI
- [sustainableaigroup/CLEER: CLEER dashboard and data public repo.](https://github.com/sustainableaigroup/CLEER)
- AIEnergyScore (AI Energy Score) - https://huggingface.co/AIEnergyScore/spaces 
- https://github.com/WimCasteels/SustainableAIv2 - dit is een applicatie die bewustwording aanhaalt

## werkmethode
ik wil een applicatie maken met verschillende modules, die via een AI programmeerbaar zijn, en die telkens hetzelfde stramien volgen. Dit stramien staat beschreven in Leerpaden sustainable AI.pdf, met enkele voorbeelden in een andere context.

## eerste stappen

ik wil een PRD.md file in de docs met noodzakelijke features:
- ik wil een webapplicatie
- ik wil gebruiken maken van een opernrouter backend AI model
- afhaneklijk van de keuze van het AI model moeten er bepaalde CO2 gevolgen worden getoond
- er moeten leerpaden worden opgezet, die dan telkens volgens hetzelfde stramien worden opgezet, die leerpaden kan je opslaan in `docs/leerpaden`
- dit moet allemaal gepland worden in specs om te implementeren
- het moet ook makkelijk zijn om de applicatie modulair aan te passen
- hiervoor moet er nog veel overleg plaatsvinden
